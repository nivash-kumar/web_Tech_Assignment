Experiment 3. Design a page to display the product information such as name, brand, price and etc with table tag.

Aim

To design a web page that displays product information such as name, brand, price, and other details using the HTML table tag.

Procedure

  1. Create an HTML document with a heading for the product list.
  2. Use the <table> tag to create a table structure.
  3. Add a header row with <th> for columns such as Product Name, Brand, Price, and Category.
  4. Add data rows with <td> for each product.
  5. Use table attributes such as border, cellpadding, and cellspacing to make the table readable.

Theory

HTML tables are used to present data in rows and columns. The <table> element contains <tr> (table row) elements. Header cells use <th> and data cells use <td>. This layout is suitable for product catalogs because name, brand, price, and related fields line up clearly. Optional attributes like border, cellpadding, and cellspacing control the look of the table without CSS.

Sample Code

Index.html


            <!DOCTYPE html>
            <html lang="en">
              <head>
                <title>Product Information</title>
              </head>

            <body>
            <header>
            <h1>Product Information</h1>
            </header>

            <main>
            <h2>Available Products</h2>
            <table border="1" cellpadding="8" cellspacing="0">
              <tr>
                <th>Product Name</th>
                <th>Brand</th>
                <th>Price</th>
                <th>Category</th>
                <th>Availability</th>
              </tr>
              <tr>
                <td>Wireless Mouse</td>
                <td>Logitech</td>
                <td>Rs. 899</td>
                <td>Electronics</td>
                <td>In Stock</td>
              </tr>
              <tr>
                <td>Running Shoes</td>
                <td>Nike</td>
                <td>Rs. 4999</td>
                <td>Footwear</td>
                <td>In Stock</td>
              </tr>
              <tr>
                <td>Notebook</td>
                <td>Classmate</td>
                <td>Rs. 45</td>
                <td>Stationery</td>
                <td>In Stock</td>
              </tr>
              <tr>
                <td>Bluetooth Speaker</td>
                <td>JBL</td>
                <td>Rs. 2499</td>
                <td>Electronics</td>
                <td>Out of Stock</td>
              </tr>
            </table>
            </main>

            <footer>
            <p>Product Catalog Page</p>
            </footer>

            </body>
            </html>

Result

The result of this experiment is a web page that shows product details in a table with columns for name, brand, price, category, and availability.

Application

  • E-commerce product listings
  • Inventory and stock reports
  • Price comparison pages
  • Displaying structured data in rows and columns
