Experiment 2. Design a web site for book information, home page should contain books list, when particular book is clicked, information of the books should display in the next page.

Aim

To design a book information website where the home page shows a list of books, and clicking a book opens another page with that book's details.

Procedure

  1. Create a home page (index.html) that lists books using an unordered list.
  2. Make each book title a hyperlink using the <a> tag.
  3. Create a separate HTML page for each book (for example, book1.html, book2.html).
  4. On the detail page, display title, author, publisher, price, and a short description.
  5. Add a link on the detail page to go back to the home page.

Theory

This experiment uses hyperlinks to connect multiple HTML pages. The home page acts as a navigation list. Each <a href="filename.html"> tag loads another document in the browser. Lists organize the book titles, and headings and paragraphs present book information on the next page. This is how simple multi-page websites work without a database or JavaScript.

Sample Code

Index.html


            <!DOCTYPE html>
            <html lang="en">
              <head>
                <title>Book Store - Home</title>
              </head>

            <body>
            <header>
            <h1>Online Book Information</h1>
            <p>Click a book title to see its details.</p>
            </header>

            <main>
            <h2>Book List</h2>
            <ul>
              <li><a href="book1.html">The Alchemist</a></li>
              <li><a href="book2.html">Wings of Fire</a></li>
              <li><a href="book3.html">Harry Potter and the Philosopher's Stone</a></li>
            </ul>
            </main>

            <footer>
            <p>Book Information Website</p>
            </footer>

            </body>
            </html>

book1.html


            <!DOCTYPE html>
            <html lang="en">
              <head>
                <title>The Alchemist</title>
              </head>

            <body>
            <header>
            <h1>The Alchemist</h1>
            </header>

            <main>
            <h2>Book Information</h2>
            <p><b>Author:</b> Paulo Coelho</p>
            <p><b>Publisher:</b> HarperCollins</p>
            <p><b>Price:</b> Rs. 299</p>
            <p><b>Description:</b> A shepherd named Santiago travels in search of treasure and learns to follow his personal legend.</p>
            <p><a href="index.html">Back to Book List</a></p>
            </main>

            <footer>
            <p>Book Information Website</p>
            </footer>

            </body>
            </html>

Result

The result of this experiment is a two-page book website. The home page shows a list of books. Clicking a book title opens a new page with that book's information and a link back to the list.

Application

  • Online book catalogs and library listings
  • Product listing pages that open a details page
  • Multi-page websites using hyperlinks
  • Learning navigation between HTML documents

Conclusion

In conclusion, this experiment showed how to build a simple book information site using a list on the home page and hyperlinks to separate detail pages for each book.
