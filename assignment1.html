Experiment 1. Design a simple web page with head, body, and footer, with heading tags, image tag.

Aim

To design a simple web page with head, body, and footer, with heading tags, image tag.

Procedure

  1. To understand the basic structure of an HTML document.
  2. To use heading tags(h1, h2, h3) to organize page content.
  3. To insert and display an image using the <img> tag.
  4. To create a footer section using semantic HTML elements.

Theory

The theory behind this experiment is to understand the basic structure of an HTML document and how to use semantic HTML elements to organize content.

Sample Code

Index.html


            <!DOCTYPE html>
            <html lang="en">
              <head>
                <title>Assignment Code</title>
              </head>

            <body>
            <header>
            <h1>Assignement</h1>
            </header>

            <main>
            <p>This is the main content of the assignment.</p>
            <img src="https://via.placeholder.com/150" alt="Placeholder Image">
            </main>

            <footer>
            <p>footer of this assignemnt</p>
            </footer>

            </body>
            </html>

Result

The result of this experiment is a simple web page with a header, main content area, and footer, using semantic HTML elements.

Application

  • Web development
  • Creating personal or business websites
  • Learning HTML and web design principles

Conclusion

In conclusion, this experiment helped in understanding the basic structure of an HTML document and how to use semantic HTML elements to create a simple web page with a header, main content area, and footer.
